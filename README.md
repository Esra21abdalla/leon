# Leon - Digital Agency Landing Page

A responsive landing page for a fictional digital agency, built to practice and demonstrate modern frontend development skills.

## 🚀 Live Demo

https://esra21abdalla.github.io/leon/

## ✨ Features

- Responsive design
- Modern and clean user interface
- Navigation bar
- Services section
- Portfolio section
- About section
- Team section
- Contact section
- Responsive layout for different screen sizes

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📱 Responsive Design

The website is designed to provide a consistent experience across desktop, tablet, and mobile screen sizes.

## 🎯 Project Purpose

This project was developed to strengthen my frontend development skills and demonstrate my ability to build responsive and structured web interfaces from scratch.
